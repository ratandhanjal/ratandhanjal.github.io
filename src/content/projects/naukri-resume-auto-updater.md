A lightweight Python automation script using Selenium WebDriver to programmatically log in to Naukri.com and upload an updated resume PDF. The tool is designed to keep job-seeker profiles active and improve recruiter visibility by simulating the resume refresh workflow without any manual intervention. Supports scheduled execution for a fully hands-free experience.
